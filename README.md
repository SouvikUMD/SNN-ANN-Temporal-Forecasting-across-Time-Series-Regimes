# SNN‑ANN Temporal Forecasting Across Time‑Series Regimes

This repository contains code, experiments, and documentation for evaluating Spiking Neural Networks (SNNs) and Artificial Neural Networks (ANNs) on heterogeneous time‑series forecasting tasks. The project explores temporal encoding, cross‑regime generalization, and performance trade‑offs between neuromorphic and conventional deep learning models.

---

## Datasets

The following datasets are used in this project:

- **PeMS Traffic Dataset**  
  https://pems.dot.ca.gov/Papers/PeMS_Intro_User_Guide_v6.pdf

- **AEP Hourly Energy Consumption**  
  https://www.kaggle.com/datasets/robikscube/hourly-energy-consumption

- **Sunspot Time Series**  
  https://www.sidc.be/SILSO/infosnmto
